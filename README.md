## Entry

> Relentless

A single word describing the human this agent works for: Laith — a 21-year-old Computer Science student in Zarqa, Jordan, working an early-shift day job while running a clipping and bounty pipeline around the clock, chasing a 250 JOD Xbox Series S by the end of 2026. He hands over whole workflows, corrects fast, and never stops pushing for the next entry, the next clip, the next dollar. Relentless is the word.

- **Word count:** 1 word (limit: exactly 1 word)
- **Character count:** 10 characters

## How to run

```bash
python3 main.py
```

Prints exactly `Relentless` to stdout, with no trailing newline, and exits with code 0. Python 3.12 standard library only; deterministic, no network, clock, or randomness.
